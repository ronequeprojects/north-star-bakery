# North Star Bakery Touchstone Website

This project contains the four HTML pages and external CSS file required for the North Star Bakery client scenario.

## Files

- `index.html` — home page
- `products.html` — product categories, descriptions, price ranges, and signature-loaf figure
- `about.html` — bakery story, sourcing philosophy, and staff highlights
- `contact.html` — location, hours, and inquiry/preorder form
- `styles.css` — shared mobile-first visual design and responsive layout
- `media/` — official media supplied in Sophia Learning's Bakery ZIP file

## Rubric Features

- Four-color palette: cream `#FFF8F0`, brown `#6B3E26`, peach `#D88C5A`, charcoal `#2F2A26`
- Two font families: Georgia for headings and Arial for body text
- Mobile-first layout using Flexbox
- Media query at `48rem`
- Responsive `<picture>` element
- Meaningful image alternative text
- `<figure>` and `<figcaption>` for the Signature North Star Loaf
- Audio element with fallback text
- Labeled form controls with `<fieldset>` and `<legend>`
- Relative navigation and media paths

## Preview
